# DENTMAN's Toothbrush Challenge

A browser app that times children's toothbrushing with the front camera (Khmer / English / Japanese).
Raise the toothbrush above your head to start, raise it again to finish.

- Runs entirely in the browser. Face data and records stay on the device (localStorage); nothing is sent out (CSP blocks all external connections).
- Open on Chrome or Edge (Windows / Android) or Safari (iPad). Allow camera access.
